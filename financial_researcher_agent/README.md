# 📈 Financial Agents

Two [crewAI](https://crewai.com) crews in one app, each in its own tab:

- **📈 Financial Researcher**: type a company; the crew researches it on the web and writes a cited report.
- **🎯 Stock Picker**: type a sector; the crew finds trending listed companies, analyses them with real market
  metrics and selects the three most interesting.

> Generated by AI agents for research purposes only. Not financial advice; do not use for trading decisions.

## How it works

### 📈 Financial Researcher (`financial_researcher/`)

Two agents in sequence (`Process.sequential`):

1. **Senior Financial Researcher** (`research_task`): searches the web with Serper (`SerperDevTool`) and
   collects the company's status, history, challenges and opportunities, recent news and outlook. Every fact
   must cite a source `[n]`, and the notes end with a Sources list (title, publisher, date, URL).
2. **Market Analyst** (`analysis_task`): turns the research into a report with an executive summary,
   analysis, outlook and conclusion, keeping the citations and adding no facts of its own.

Both agents use `inject_date=True`, so they know today's date when judging what "recent" means.

### 🎯 Stock Picker (`stock_picker/`)

Three agents in sequence, with structured (Pydantic) outputs between them:

1. **News Analyst** (`find_trending_companies` → `TrendingCompanyList`): finds 5-6 trending companies in the
   sector with Serper and confirms they are publicly traded with the **Get stock metrics** tool (private
   companies come back `NOT_LISTED` and are replaced).
2. **Senior Financial Researcher** (`research_trending_companies` → `TrendingCompanyResearchList`): analyses each
   company. Its metrics come from **Get stock metrics** (`stock_picker/src/stock_picker/tools/stock_metrics.py`):
   EPS, revenue growth, gross margin, ROE and P/E from Yahoo Finance via `yfinance`, plus SMA 30/50/100/200,
   MACD (12/26/9) and 10-day momentum computed from a year of daily prices. Missing values are "unknown", never
   estimated. One tool call fetches all the tickers.
3. **Stock Picker** (`pick_best_companies`): picks the three best candidates and explains why the others weren't
   chosen.

Safeguards in `crew.py`: a step limit and a time limit per agent (so a run can't loop), `response_format` on the
agents with structured outputs (so the model can't answer with the JSON schema instead of data), and crew memory
with an explicit embedding model (`text-embedding-3-small`).

### The app

`app.py` imports both crews without changing them. While a crew works, the **live log** shows each tool call and
each finished task (via crewAI's `step_callback` and `task_callback`); then the results appear in tabs and as
downloadable files. crewAI cloud tracing is turned off for the web app (`STOCK_PICKER_TRACING=false`), so visitors'
runs aren't uploaded and runs don't wait for a terminal prompt.

## Files

| File | Purpose |
|------|---------|
| `README.md` | Space configuration (YAML block at the top) and this documentation. |
| `app.py` | Gradio app and Space entry point: the two tabs, the live log and saving the results. |
| `requirements.txt` | Packages the Space installs: `crewai[tools]`, `gradio`, `python-dotenv`, `yfinance`. |
| `financial_researcher/` | The Financial Researcher crewAI project. Runs on its own with `crewai run`. |
| `stock_picker/` | The Stock Picker crewAI project, including the Get stock metrics tool. Runs on its own with `crewai run`. |

## Configuration

Add these as **secrets** in the Space (Settings → Variables and secrets). Locally, `app.py` reads them from
the nearest `.env` file.

| Secret | Used for |
|--------|----------|
| `OPENAI_API_KEY` | All agents use `openai/gpt-4o-mini` (set in each `config/agents.yaml`), and the Stock Picker's memory uses OpenAI embeddings. |
| `SERPER_API_KEY` | Web search ([serper.dev](https://serper.dev)). |

Optional **variables** for the Stock Picker:

| Variable | Default | Purpose |
|----------|---------|---------|
| `EMBEDDING_MODEL` | `text-embedding-3-small` | Embedding model for the crew's memory. |
| `FINDER_MAX_ITER`, `RESEARCHER_MAX_ITER`, `PICKER_MAX_ITER` | 12, 18, 5 | Maximum steps per agent per task. |
| `FINDER_MAX_SECONDS`, `RESEARCHER_MAX_SECONDS`, `PICKER_MAX_SECONDS` | 300, 600, 300 | Time limit per agent per task. |

## Run locally

```bash
cd financial_researcher_agent
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

## Deploy

From the repo root: `./deploy_space.sh financial_researcher_agent` (→ `MiguelBayanSoares/Financial_Researcher`).

Each run is saved in `output/runs/<date>-<research|picks>-<name>/`. The Space clears this folder when it restarts.
Each tab runs one request at a time; other users wait in the queue.
