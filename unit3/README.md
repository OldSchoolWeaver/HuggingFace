# 📈 Financial Researcher

Type a company name. A [crewAI](https://crewai.com) crew researches it on the web and writes a cited report.

> Generated by AI agents for research purposes only. Not financial advice; do not use for trading decisions.

## How it works

The crew runs two agents in sequence (`Process.sequential`):

1. **Senior Financial Researcher** (`research_task`): searches the web with Serper (`SerperDevTool`) and
   collects the company's status, history, challenges and opportunities, recent news and outlook. Every fact
   must cite a source `[n]`, and the notes end with a Sources list (title, publisher, date, URL).
2. **Market Analyst** (`analysis_task`): turns the research into a report with an executive summary,
   analysis, outlook and conclusion, keeping the citations and adding no facts of its own.

Both agents use `inject_date=True`, so they know today's date when judging what "recent" means.

The app shows a **live log** while the crew works (each tool call and each finished task, via crewAI's
`step_callback` and `task_callback`), then the **report**, the researcher's **notes and sources**, and both
as downloadable files.

## Files

| File | Purpose |
|------|---------|
| `README.md` | Space configuration (YAML block at the top) and this documentation. |
| `app.py` | Gradio app and Space entry point. Imports `ResearchCrew` from the crewAI project below without changing it. |
| `requirements.txt` | Packages the Space installs: `crewai[tools]`, `gradio`, `python-dotenv`. |
| `financial_researcher/` | The crewAI project, unchanged: agents in `config/agents.yaml`, tasks in `config/tasks.yaml`, crew in `crew.py`. Runs on its own with `crewai run`. |

## Configuration

Add these as **secrets** in the Space (Settings → Variables and secrets). Locally, `app.py` reads them from
the nearest `.env` file.

| Secret | Used for |
|--------|----------|
| `OPENAI_API_KEY` | Both agents use `openai/gpt-4o-mini` (set in `config/agents.yaml`). |
| `SERPER_API_KEY` | Web search ([serper.dev](https://serper.dev)). |

## Run locally

```bash
cd unit3
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

## Deploy

From the repo root: `./deploy_space.sh unit3` (→ `MiguelBayanSoares/Financial_Researcher`).

Each run is saved in `output/runs/<date>-<company>/` (`report.md`, `research.md`). The Space clears this folder
when it restarts. One research runs at a time; other users wait in the queue.
